# MarketSight Analytics 📈

A full-stack predictive financial forecasting dashboard designed to provide dynamic asset trajectory analysis and historical market insights. 

## Features
* **Live Market Data:** Integrates directly with financial APIs to retrieve accurate 1-year OHLCV data.
* **Predictive Analytics:** Implements Linear Regression models to forecast 7-day to 30-day asset price trajectories.
* **Interactive Dashboard:** Dynamic user interface featuring responsive charting for immediate visual analysis.
* **Decoupled Architecture:** High-performance Python backend serving a modern React frontend.

## Tech Stack
* **Frontend:** React, Node.js, Recharts, Tailwind CSS
* **Backend:** Python, FastAPI, scikit-learn, yfinance
